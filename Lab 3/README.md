# Monthly Temperature Prediction using Regression

This project predicts month-wise temperature using different regression models:

- Linear Regression (from scratch)
- Polynomial Regression
- Seasonal Sin/Cos Regression
- Fourier Series Regression

Model performance is evaluated using:
- MSE (Mean Squared Error)
- MAE (Mean Absolute Error)
- R² Score

The Fourier model gave the best performance as temperature follows a seasonal cycle.
